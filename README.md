# AI Advent Challenge #9

This repository contains my homework and learning results from the **AI Advent Challenge #9** course. It is intended for sharing completed work with tutors.

Each week of the course has its own directory. Individual days/tasks are
presented as commits rather than separate folders or branches. For example,
the `Week0 Task0` commit represents the first day of the first week.

Week directories include:

- `week0/`
- `week1/`
- and so on

Many assignments include a video demonstration. These videos are collected in the [AI Advent Challenge #9 playlist](https://www.youtube.com/playlist?list=PLY0ndpx99mvs).
